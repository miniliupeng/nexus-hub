# 通用规格 04：通用对象存储与预签名直传服务 (Object Storage & Pre-signed URL)

## 📌 1. 设计初衷与通用价值
任何现代 Web 业务系统都需要处理图片、视频或附件上传。传统“前端 -> 后端 -> 磁盘”的路径严重浪费后端算力与带宽。
本模块作为通用基础设施，封装 MinIO / AWS S3 客户端，对外提供统一的 **短时效安全预签名 URL 直传生成能力**。

---

## 🔐 2. 安全与时效机制
1. **时效控制**：签发的上传预签名 URL 默认 15 分钟失效；
2. **体积与 MIME 校验**：签发前检查前端上报的文件后缀与 MIME 类型，拒绝 `.sh`, `.exe`, `.html` 等高危脚本；
3. **隔离命名空间**：通过 UUID + 日期哈希生成全局唯一 Object Key，防止文件重名覆盖。
